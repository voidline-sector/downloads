# Voidline Uplink downloads

Installers for the Voidline Uplink desktop app.

This repository holds releases and nothing else. The app's source is not here,
and the "Source code" archives GitHub attaches to every release contain only
this README.

**Get the newest installer** from <https://voidline.gg/downloads/>, or from
[the latest release](https://github.com/voidline-sector/downloads/releases/latest).

- **Windows (x64):** `Voidline-Uplink-Setup.exe`. The installer is not signed
  yet, so Windows may warn before it runs: choose More info, then Run anyway.
- **macOS and Linux:** not yet. Every sector also works in a browser.

Each release is tagged with the app's version and lists what that installer
adds. The file name stays the same from release to release, so this link
always fetches the newest one:
<https://github.com/voidline-sector/downloads/releases/latest/download/Voidline-Uplink-Setup.exe>
